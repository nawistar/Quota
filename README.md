## 💬 주변인 데이터 기록 프로그램

Tkinter 기반의 **주변인 데이터 기록 프로그램**.
닫을 때 데이터가 자동으로 `quotes_data.txt`에 JSON으로 저장.

---

## ✨ 주요 기능

- **즐겨찾기**: 자주 찾는 인물을 상단에 고정하여 빠른 접근 지원
- **전체 인물 목록**: 가나다순 자동 정렬 및 스크롤바 지원
- **선택 해제**: 빈 공간 클릭 또는 버튼으로 선택 상태 초기화
- **어록 관리**: 줄바꿈(`\n`)을 활용한 데이터 실시간 추가 및 수정
- **자동 저장**: 프로그램 종료 시 변경된 데이터 자동 저장

---

## 🚀 사용 방법

1. Python 설치 확인ㄱ (Tkinter 기본 내장).
2. 아래 코드를 `app.py` 파일로 저장.
3. 터미널 || CMD에서 실행:
   ```bash
   python app.py
   ```
