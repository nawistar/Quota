# 👄 Quota 🗯️

## 👁️‍🗨️ 주변인 데이터 기록 프로그램

Python Tkinter 기반의 **주변인 데이터 기록 프로그램**. 인물별 어록과 정보를 기록하고 관리하며, JSON 파일을 통해 데이터를 저장한다.

---

## ✨ 주요 기능

- **인물 관리**: 인물 추가 및 삭제, 가나다순 정렬
- **즐겨찾기**: 자주 찾는 인물 등록 및 빠른 접근
- **어록·정보 관리**: 인물별 어록과 정보 기록 및 수정
- **테마 설정**: 라이트 모드와 다크 모드 지원
- **자동 저장**: 30초 간격 및 프로그램 종료 시 데이터 저장

---

## 🚀 사용 방법

1. Python 설치 확인
2. 코드를 `app.py`로 저장
3. 터미널 또는 CMD에서 실행

```bash
python app.py
```

데이터는 `quotes_data.json`, 테마 설정은 `theme.json`에 저장된다.
